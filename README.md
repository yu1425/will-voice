# WILL Voice

WILL.tennisの開催を支えるスマホ向け進行アシスタントです。PCでも幅480pxの画面で表示します。

- `/`：うぃる公式キャラクターサイトのHOME。進行、チャット、設定、使い方への入口
- `/flow`：自動進行 / 個別進行を切り替えて使用
- `/chat`：うぃるに質問（現在はルールベースの返答）
- `/settings`：進行・チャットそれぞれの設定入口
- `/guide`：初めて使う運営担当向けの使い方

## 起動

Node.js 18以上を用意し、以下を実行します。

```sh
npm install
npm run dev
```

ブラウザで `http://localhost:3000/flow` を開きます。iPadではSafariの共有メニューから「ホーム画面に追加」できます。案内を確実に流すには、進行画面を開いたまま使ってください。

## 標準2時間の自動進行

画面上部の「開催準備」でコート数を選択し、右上メニューの「設定」で「チャイムを試聴」と「テスト再生」を行い、「自動進行を開始」を押します。全体の自己紹介はゲーム前です。

| 経過  | 案内                         |
| ----- | ---------------------------- |
| 00:00 | 開始あいさつ・ショートラリー |
| 00:05 | ボレーボレー                 |
| 00:10 | ロングラリー                 |
| 00:20 | クロスラリー                 |
| 00:30 | サーブ・リターン             |
| 00:35 | サーブ・リターン交代         |
| 00:40 | 乱数表の説明                 |
| 00:43 | 試合ルール                   |
| 00:46 | 自己紹介                     |
| 00:50 | ゲーム開始                   |
| 01:45 | ミニゲーム（リレーラリー）   |
| 01:57 | 終了あいさつ・片付け         |
| 02:00 | 進行完了（音声なし）         |

上部で現在・次・その次のメニューと開催全体の進捗を確認できます。操作は開始、一時停止・再開、終了に統合しています。

- 一時停止は時計と案内を一緒に止めます。再開すると時計と中断したWAVが止めた位置から続きます。チャイム途中ならチャイムから再開します。
- 進行中に項目を選ぶとその時刻に移動して案内し、一時停止中に選ぶとその項目で待機します。
- 独立した「音声停止」「聞き直し」ボタンはありません。同じ項目の先頭からやり直す場合も項目移動を使います。
- 終了はプレイヤー右側の終了ボタンから確認後に実行し、時計・音声・保存セッションを消します。
- モード移動、別ページ移動、ページ非表示で全体を一時停止します。再表示やリロードだけでは勝手に時計・音声を開始しません。
- session v4はv1/v2/v3保存データも読み込みます。旧状態は現在位置で一時停止として復元し、過去の案内をまとめて再生しません。
- 音声読み込み失敗時も自動進行を一時停止し、再開操作で現在の案内を再試行します。

## 個別進行

項目一覧や左右の矢印で案内を選び、中央の「この案内を再生」で再生します。同じボタンが「一時停止」「続きから再生」に切り替わります。別項目の選択は音声を止めて選択を変えるだけで、自動では再生しません。

練習タイマーと声かけは個別進行だけの補助ツールです。声かけは選んだボタンで再生し、同じボタンで止められます。タイマー・声かけは共通音量のずんだもんWAVを使います。自動進行に移動すると補助タイマーも一時停止します。

コート数は上部で設定し、自動進行セッション中は変更不可です。個別進行の「案内文の調整」で一時編集できます。編集文は選択音声で合成し、項目移動で元に戻ります。

## 原稿とずんだもん音声

共通原稿は `lib/flowScripts.json` です。表示文・時刻・STEP・コート数・録音パスをまとめています。

```
lib/flowScripts.json
  → lib/voicevoxText.ts で読み補正
  → lib/flowScripts.ts（displayText / voiceText）
  → lib/standardTwoHourFlow.ts（自動進行）
  → lib/tennisFlowScripts.ts（個別進行）
  → scripts/generate-flow-audio.mjs（音声生成）
```

新しい録音は `public/audio/flow/v2/` にあります。クロスラリー、サーブ・リターン、乱数表は1面/2面の文面を用意しています。12イベント＋3つの追加variant＋音声テストの16WAVです。

自動進行と未編集の個別STEPは生成済みのずんだもん音声を再生します。ローカルENGINEは再生時には不要で、Vercel Previewでも同じファイルを使用します。録音の再生失敗時は画面に案内し、標準音声へフォールバックしません。元の音声ファイルは残しています。

個別進行の固定声かけ6種類とタイマー終了案内も、`lib/flowCues.json` を原稿として `public/audio/flow/extras/` のずんだもんWAVを再生します。共通音量・再生中の音量変更・停止に従い、チャットの音声モードに関わらず録音を使用します。タイマー操作と声かけ操作は別ブロックです。タイマーの一時停止は残り時間を保持し、声かけの停止でタイマーを止めることはありません。

読み補正はVOICEVOX用の文だけに適用します。WILL.tennis→ウィルテニス、乱数表→らんすうひょう、4ポイント先取→よんポイントせんしゅ、2人→ふたり、3球→さんきゅう、1列→いちれつ、2本→にほん、3本→さんぼん、人を指す「方」→かた、初参加→はじめて参加などを補正します。「方向」「方法」「聞こえ方」は維持します。

### 音声の再生成

ローカルVOICEVOX ENGINEを起動し、`http://127.0.0.1:50021/speakers` が応答することを確認します。話者一覧から「ずんだもん」「ノーマル」を名前で検索してstyleIdを確定します。停止している場合は生成も停止し、代替音声は作りません。

```sh
node scripts/generate-flow-audio.mjs
# 既存監査結果を確認して更新する場合
node scripts/generate-flow-audio.mjs --replace
# 声かけ6件とタイマー終了案内の生成（初回）
node scripts/generate-flow-audio.mjs --extras
```

`reports/flow-audio-v2-audit.json` に全文、正規化後のvoiceText、speaker/style、kana、accent phrases、読みの検証結果、生成ファイル、byte数、秒数を保存します。生成ツールは既存監査ファイルがある場合、明示的な `--replace` なしで上書きしません。

声かけ・タイマーの同じ監査項目は `reports/flow-extras-audio-audit.json` に保存します。

音声クレジット：**VOICEVOX:ずんだもん**

## チャットと追加音声設定

`/chat` はテキストまたはマイクで質問できます。返答ルールは `lib/mockReplyRules.ts`、将来のAI API接続箇所は `lib/generateWillReply.ts` です。APIキーをブラウザへ置かないでください。

チャットの設定でブラウザ標準音声やローカルVOICEVOXを選べます。VOICEVOX合成は `/api/voicevox/tts` を経由し、利用できない場合にチャットや編集原稿は標準音声を使います。この設定は自動進行の録音案内には影響しません。

ローカル合成には `.env.example` の `VOICEVOX_ENGINE_URL` を参照してください。VercelのサーバーからローカルPCのENGINEには接続できません。自動進行の生成済み音声はこの制限の影響を受けません。

## 検証

```sh
node scripts/test-flow.mjs
npx tsc --noEmit
npm run build
git diff --check
```

ブラウザ監査はPlaywrightが利用できる環境で実行します（アプリの依存追加なし）。既存ブラウザには接続せず、隔離されたブラウザを起動します。

```sh
node scripts/test-unified-flow.mjs
WILL_AUDIT_URL=http://127.0.0.1:3001 WILL_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node scripts/audit-unified-flow.mjs
```

`WILL_AUDIT_OUTPUT`で証跡出力先、`WILL_CHROME_PATH`で任意のインストール済みChromeを指定できます。実WAV・AudioContextを使用し、時計と音声の同時停止／再開、項目移動、ページ移動、設定・共通音量、手動タイマー、UIの表示、キーボードを検証します。従来の `audit-flow-*.mjs` とv2〜v6レポートは旧操作仕様の証跡であり、新仕様の監査とは区別しています。

## Preview運用

既存feature branchのPRを更新し、Git連携が生成するVercel Previewを確認します。mainへのmergeやProductionへのデプロイは、Preview確認後の別作業です。

### 共通音量とメニュー

右上メニューは「進行」「うぃるに聞く」「設定」「使い方」の順です。Macのホバー、クリック、iPadのタップ、キーボード操作に対応します。下部のページナビゲーションはありません。

共通音量0〜100%は再生中の録音・VOICEVOX・チャイムへ反映し、既存の `will-recorded-volume` 保存キーを維持しています。チャイムの音程・余韻と全23WAVは今回変更していません。設定の試聴は自動進行を一時停止し、試聴後にプレイヤーの再開で続けます。音量変更とメニューを開く操作だけでは進行を止めません。

## 統合プレイヤー（PR #6 追加改修）

自動進行は「開始・一時停止・再開・終了」とメニュー移動だけで操作します。時計と案内は同時に停止・再開し、一時停止中の項目選択では音を鳴らさず再開を待ちます。自動進行に独立した音声停止・聞き直し・練習タイマーはありません。ページ／モード移動時も全体を一時停止します。

個別進行は項目選択と1つの再生／一時停止ボタンを中心にし、練習タイマー・声かけは個別進行に限定しています。自動・個別の項目一覧は共通の3列×4行グリッドにして、12項目を少ない高さで確認できます。開催準備は画面上部、ページ移動・各コンテンツの設定・使い方は右上のメニューにあります。下部ナビゲーションは撤去しています。

`/` は「うぃる」を親にした公式キャラクターHOMEです。進行とチャットを主要コンテンツ、設定と使い方をサポートとして分け、今後キャラクター関連コンテンツを追加できる構造にしています。設定は共通で一つにせず、`/settings` から進行設定・チャット設定へ分岐します。

設計・仕様・監査は `docs/unified-flow.md` を参照してください。旧監査レポートは当時の仕様の証跡として残しており、今回の操作仕様を証明するものではありません。
