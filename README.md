# WILL Voice

WILL.tennisの開催を支えるスマホ向け進行アシスタントです。PCでも幅480pxの画面で表示します。

- `/flow`：自動進行 / 個別進行を切り替えて使用
- `/guide`：初めて使う運営担当向けの使い方
- `/chat`：うぃるに質問（現在はルールベースの返答）
- `/`：`/flow`に移動

## 起動

Node.js 18以上を用意し、以下を実行します。

```sh
npm install
npm run dev
```

ブラウザで `http://localhost:3000/flow` を開きます。iPhoneではSafariの共有メニューから「ホーム画面に追加」できます。案内を確実に流すには、進行画面を開いたまま使ってください。

## 標準2時間の自動進行

コート数を選択し、チャイムを試聴して音声テストを行い、「自動進行を開始」を押します。全体の自己紹介はゲーム前です。

| 経過 | 案内 |
| --- | --- |
| 00:00 | 開始あいさつ・ショートラリー |
| 00:05 | ボレーボレー |
| 00:10 | ロングラリー |
| 00:20 | クロスラリー |
| 00:30 | サーブ・リターン |
| 00:35 | サーブ・リターン交代 |
| 00:40 | 乱数表の説明 |
| 00:43 | 試合ルール |
| 00:46 | 自己紹介 |
| 00:50 | ゲーム開始 |
| 01:45 | ミニゲーム（リレーラリー） |
| 01:57 | 終了あいさつ・片付け |
| 02:00 | 進行完了（音声なし） |

上部に現在のメニュー、経過時間、残り時間、進捗、開始・終了予定時刻、次の案内と切替までの時間を表示します。Date.now()と開始時刻から1秒ごとに計算し、一時停止時間を差し引きます。

- 「進行を一時停止」は時計と今の音声を止めます。「進行を再開」で時計が再開します。
- 「音声を停止」は音声とチャイムだけを止め、時計は続きます。次のメニューでは案内が流れます。
- タイムラインから移動できます。実行中は画面内に確認を表示し、移動すると時計も同期します。
- 2時間で無音の進行完了になります。操作ボタンの位置は変わりません。
- 個別進行へ切り替えても時計は続きます。その画面では自動の案内は鳴りません。
- 別ページに移動すると、音声・チャイム・遅延案内をキャンセルします。
- 戻る・reload時は現在時刻に追いつき、過去の音声をまとめて流しません。
- 開始時刻、一時停止時間、状態、発火済イベント、コート数をlocalStorageに保存します。保存データv1/v2は新フローへ移行します。
- ブラウザのバックグラウンド化・画面ロック中は自動案内を保証できません。復帰時は時刻だけ同期します。

## 個別進行

同じ原稿を12STEPとして選択し、任意のタイミングで再生します。「前へ」「次へ」やSTEP一覧で移動できます。再生、一時停止・再開、停止の操作位置は固定です。STEPを移動すると再生中の音声を止めます。

「タイマー・声かけ」に5分/10分タイマーと注意喚起があります。自動進行に切り替えた間は手動タイマーの音声は鳴りません。「コート数・案内を調整」でコート数と一時的な原稿編集を行えます。編集済み原稿や声かけは合成音声を使い、STEP移動で編集を解除します。自動進行中のコート数は固定します。

## 原稿とずんだもん音声

共通原稿は `lib/flowScripts.json` です。表示文・時刻・STEP・コート数・録音パスをまとめています。

```
lib/flowScripts.json
  → lib/voicevoxText.ts で読み補正
  → lib/flowScripts.ts（displayText / voiceText）
  → lib/standardTwoHourFlow.ts（自動進行）
  → lib/tennisFlowScripts.ts（個別進行）
  → scripts/generate-flow-audio.mjs（音声生成）
```

新しい録音は `public/audio/flow/v2/` にあります。クロスラリー、サーブ・リターン、乱数表は1面/2面の文面を用意しています。12イベント＋3つの追加variant＋音声テストの16WAVです。

自動進行と未編集の個別STEPは生成済みのずんだもん音声を再生します。ローカルENGINEは再生時には不要で、Vercel Previewでも同じファイルを使用します。録音の再生失敗時は画面に案内し、標準音声へフォールバックしません。元の音声ファイルは残しています。

読み補正はVOICEVOX用の文だけに適用します。WILL.tennis→ウィルテニス、乱数表→らんすうひょう、4ポイント先取→よんポイントせんしゅ、2人→ふたり、3球→さんきゅう、1列→いちれつ、2本→にほん、3本→さんぼん、人を指す「方」→かた、初参加→はじめて参加などを補正します。「方向」「方法」「聞こえ方」は維持します。

### 音声の再生成

ローカルVOICEVOX ENGINEを起動し、`http://127.0.0.1:50021/speakers` が応答することを確認します。話者一覧から「ずんだもん」「ノーマル」を名前で検索してstyleIdを確定します。停止している場合は生成も停止し、代替音声は作りません。

```sh
node scripts/generate-flow-audio.mjs
# 既存監査結果を確認して更新する場合
node scripts/generate-flow-audio.mjs --replace
```

`reports/flow-audio-v2-audit.json` に全文、正規化後のvoiceText、speaker/style、kana、accent phrases、読みの検証結果、生成ファイル、byte数、秒数を保存します。生成ツールは既存監査ファイルがある場合、明示的な `--replace` なしで上書きしません。

音声クレジット：**VOICEVOX:ずんだもん**

## チャットと追加音声設定

`/chat` はテキストまたはマイクで質問できます。返答ルールは `lib/mockReplyRules.ts`、将来のAI API接続箇所は `lib/generateWillReply.ts` です。APIキーをブラウザへ置かないでください。

チャットの設定でブラウザ標準音声やローカルVOICEVOXを選べます。VOICEVOX合成は `/api/voicevox/tts` を経由し、利用できない場合にチャットや編集原稿は標準音声を使います。この設定は自動進行の録音案内には影響しません。

ローカル合成には `.env.example` の `VOICEVOX_ENGINE_URL` を参照してください。VercelのサーバーからローカルPCのENGINEには接続できません。自動進行の生成済み音声はこの制限の影響を受けません。

## 検証

```sh
node scripts/test-flow.mjs
npx tsc --noEmit
npm run build
git diff --check
```

ブラウザ監査はPlaywrightが利用できる環境で実行します（アプリに実行時依存は追加していません）。

```sh
WILL_AUDIT_URL=http://127.0.0.1:3001 \
WILL_PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
node scripts/audit-flow-browser.mjs
```

必要なら `WILL_CDP_URL` で既存Chromiumに接続できます。実際のWAVをdecode/playし、時刻を進めて全イベント順を検証します。結果は `reports/flow-v2-browser-audit.json` と `reports/flow-v2-*.png` です。
